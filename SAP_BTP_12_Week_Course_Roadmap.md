# SAP BTP Learning Roadmap — 12 Weeks

## Goal

Build practical SAP BTP, CAP, Fiori, and Integration skills while leveraging an existing Shopify/full-stack development background.

**Target career path:**

Shopify / Full-Stack Developer  
→ SAP BTP Developer  
→ SAP CAP / Integration Developer  
→ SAP Technical Consultant  
→ SAP Integration / Solution Architect

**Recommended pace:** 9–10 hours/week  
**Duration:** 12 weeks  
**Approach:** Learn → Build → Document → Explain

---

# What NOT to Focus On Yet

Do not spend your first three months going deep into:

- [ ] Legacy ABAP
- [ ] SAP functional consulting
- [ ] FI/CO configuration
- [ ] MM configuration
- [ ] SD configuration
- [ ] SAP Basis administration
- [ ] SAP HCM configuration
- [ ] Large-scale legacy SAP customization

You should understand SAP business processes at a high level, but your initial specialization should remain **technical**.
